Tạo báo cáo dashboard từ file Excel hoặc CSV

Tải file .xlsx hoặc .csv, chọn cột nhóm, cột giá trị và cột ngày. Công cụ dựng biểu đồ, bảng chi tiết và bản in báo cáo. Số kiểu Việt Nam (1.234.567) và ngày dd/mm/yyyy được đọc đúng.

Cách dùng

  1. Tải file Excel (.xlsx, .xls) hoặc CSV lên.
  2. Chọn cột nhóm (ví dụ sản phẩm), cột giá trị (ví dụ doanh thu) và cột ngày nếu có.
  3. Bấm tạo báo cáo, lọc theo nhóm hoặc khoảng giá trị, rồi xuất PDF.

Câu hỏi thường gặp

File của tôi có bị tải lên máy chủ không?

Không. File được đọc và xử lý ngay trong trình duyệt của bạn.

Ngày 01/11/2026 được hiểu là ngày nào?

Luôn hiểu theo kiểu Việt Nam: ngày 1 tháng 11. File dữ liệu kiểu Mỹ (tháng/ngày) sẽ cho kết quả sai ngày.

Số 1.500 được hiểu là bao nhiêu?

Một nghìn năm trăm. Nếu file dùng dấu chấm làm dấu thập phân kiểu Anh thì kết quả sẽ lệch.

Phần nhận xét tự động có phải AI không?

Không. Đó là câu mẫu ghép từ số liệu đã tính, chỉ để đọc nhanh.
