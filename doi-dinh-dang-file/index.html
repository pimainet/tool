Đổi định dạng Excel, CSV, JSON và ảnh

Chuyển qua lại giữa Excel, CSV và JSON, hoặc đổi định dạng nhiều ảnh cùng lúc. CSV xuất ra có BOM UTF-8 để Excel hiển thị đúng tiếng Việt, số có 0 đầu như số điện thoại được giữ nguyên.

Chuyển định dạng ảnh

Cách dùng

  1. Tải file Excel, CSV hoặc JSON lên (chọn sheet nếu có nhiều sheet).
  2. Chọn định dạng xuất: JSON, CSV hoặc Excel.
  3. Với ảnh: chọn nhiều ảnh, chọn định dạng đích rồi bấm chuyển đổi.

Câu hỏi thường gặp

Mở file CSV bằng Excel bị lỗi font thì sao?

File CSV xuất từ công cụ này có BOM UTF-8 nên Excel hiển thị đúng tiếng Việt. Nếu file có sẵn đã lỗi, dùng công cụ Chuẩn hóa tiếng Việt để sửa.

Số điện thoại có bị mất số 0 đầu không?

Không. Khi đọc CSV, giá trị có số 0 đầu được giữ ở dạng chữ.

Ảnh PNG trong suốt chuyển sang JPG ra sao?

JPG không có nền trong suốt nên nền được tô trắng.
